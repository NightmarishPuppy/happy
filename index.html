Как установить
      Синхронизация не настроена

      Это необязательно. Без синхронизации список работает и хранится на этом устройстве.

      Если хотите один список на нескольких устройствах, его можно хранить в вашем GitHub. Настраивается один раз на каждом устройстве:

      1. Откройте страницу создания ключа на GitHub.
      2. В поле Expiration выберите No expiration. Галочка gist уже стоит, больше ничего не отмечайте.
      3. Внизу нажмите Generate token и скопируйте ключ, он начинается с ghp_.
      4. Вставьте его сюда и нажмите «Подключить».
